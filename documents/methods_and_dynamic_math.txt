================================================================================
 Canonical methods (Scaffold-GS fork)
================================================================================

Entry:
  bash train_method.sh --method <baseline|moe|moe_gnn> -d <data> -g 0
  bash sweep.sh --suite mip360 -g 0

Methods:
  1) Scaffold-GS (baseline)  --method baseline
  2) flat MoE                --method moe
  3) MoE+GNN                 --method moe_gnn

Notes:
  - MoE+GNN = warm-start flat MoE MLPs → flat MoE + dual AnchorGNN router,
    densify ON (no ply), another 30k. See documents/moe_gnn_results.txt.
  - Legacy alias: moe_continue → moe_gnn
  - Order per scene: baseline → moe → moe_gnn (moe_gnn needs moe ckpt)


================================================================================
 0. SHARED SCAFFOLD-GS BACKBONE
================================================================================

Scene is voxelized into N anchors. Anchor i has:
  x_i in R^3          position
  f_i in R^C          learnable feature  (f_v), C = feat_dim
  offsets / scaling   → neural Gaussians decoded by attribute MLPs

Per view, for visible anchors:
  build view features u from (f_v, view direction, optional distance)
  decode opacity / color / covariance via attribute networks
  rasterize with differentiable Gaussian splatting


================================================================================
 1. Scaffold-GS baseline
================================================================================

Script: train_method.sh --method baseline   →  outputs/<data>/baseline/

Shared MLP per attribute (opacity, cov, color). num_experts=1.


================================================================================
 2. Flat MoE
================================================================================

Script: train_method.sh --method moe   →  outputs/<data>/moe/

E=8 experts, Top-2 after warmup (dense softmax for first moe_warmup iters).
Point-wise router on f_v; experts on view-conditioned u.
Aux losses: opacity reg, Switch load-balance, router entropy (after warmup).


================================================================================
 3. MoE+GNN
================================================================================

Script: train_method.sh --method moe_gnn   →  outputs/<data>/moe_gnn/

Same flat MoE experts + dual router:
  h_gnn = AnchorGNN(pos, f_v)     # k-NN attention, 2 layers, k=16
  z = z_base(f_v) + γ · z_gnn([f_v ‖ h_gnn])

Warm-start experts + base router from finished flat MoE; zero-init gnn_router.
Densify from SfM (no ply). Train +30k.

Results: documents/moe_gnn_results.txt
